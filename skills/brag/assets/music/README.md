# Music

## Happy Beats / Business Moves

Bundled tracks by Sascha Ende ([ende.app](https://ende.app/en)):

- `happy-beats-business-moves-vol-1-by-ende-dot-app.mp3` (2:44) — `default`, `launch`
- `happy-beats-business-moves-vol-9-by-ende-dot-app.mp3` (1:54) — `yc-parody`
- `happy-beats-business-moves-vol-10-by-ende-dot-app.mp3` (1:00) — short punchy cut, not a default bed
- `happy-beats-business-moves-vol-11-by-ende-dot-app.mp3` (1:28) — `app-store`
- `happy-beats-business-moves-vol-12-by-ende-dot-app.mp3` (1:58) — `polished`, `demo`

The other volumes of the album are the same corporate-happy palette, so they are not vendored. Vol. 10 stays for a one-minute cut.

Cue presets live in `cues/`:

- `<track-stem>.music-cues.json` contains full-track beat and strong-cue metadata.
- `<track-stem>.music-cues.md` contains compact planning guidance for the first 20-25 seconds.

These files are generated by `skills/brag/scripts/analyze_music_cues.py`. The default pipeline reads bpm and downbeat from `../palette.json` instead.
